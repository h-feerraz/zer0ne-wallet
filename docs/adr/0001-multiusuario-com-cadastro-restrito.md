# Multiusuário desde o início, com cadastro restrito

O MVP é para uso próprio, mas o objetivo futuro é atender outras pessoas. Por isso, o sistema já nasce com login e dados separados por usuário, porque adicionar isso depois exigiria refazer boa parte dele. O cadastro fica limitado a uma lista de e-mails permitidos, o que adia as obrigações de manter dados de terceiros, como as previstas na LGPD. Abrir o cadastro passa a ser uma etapa posterior, sem refazer a tela.
